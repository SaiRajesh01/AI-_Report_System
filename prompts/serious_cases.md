# Section: Serious Cases / 15-Day Alerts

Write the "Serious Cases / 15-Day Alerts" section of a PADER report.

This section analyzes the serious and expedited (15-day Alert) cases submitted during the reporting interval.

## Required content (use ONLY the evidence provided):

1. **Overview**: State the total number of serious cases and expedited (15-day Alert) cases. Note that in this dataset, serious and expedited populations are nearly identical.

2. **Seriousness criteria breakdown table**:
   - Death: count and percentage
   - Life-threatening: count and percentage
   - Hospitalization: count and percentage
   - Disability/incapacity: count and percentage
   - Congenital anomaly: count and percentage
   - Other medically important: count and percentage
   - Note these are NOT mutually exclusive — one case can meet multiple criteria.

3. **Multi-criteria analysis**: How many cases met 1, 2, or 3+ criteria.

4. **Fatal cases**: State the number and percentage of fatal cases.

5. **15-Day Alert summary by source**:
   - Spontaneous reports vs. study reports
   - Fatal vs. non-fatal among expedited cases

6. **Expectedness**: Explicitly state that expectedness (labelled/unlabelled) could not be determined because no product label/CCDS was supplied for this exercise.

## Formatting:
- Use Markdown tables for the seriousness criteria.
- Brief analytical prose connecting the data points.
