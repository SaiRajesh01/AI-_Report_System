# Section: Summary Analysis of Cases

Write the "Summary Analysis of Cases" section of a PADER report.

This section provides structured aggregate tables and summaries of the case data.

## Required content (use ONLY the evidence provided):

1. **Case volume table**:
   - Total cases
   - Serious cases (count and percentage)
   - Non-serious cases
   - Expedited / 15-Day Alert cases
   - Report type breakdown (spontaneous vs. study)

2. **Patient demographics tables**:
   - Sex distribution (male, female, unknown) with counts and percentages
   - Age group distribution with counts (Neonate, Infant/Toddler, Child, Adolescent, Adult, Elderly)
   - Age statistics (mean, median, min, max)
   - Note missing age/sex data

3. **Geographic distribution table**:
   - Top reporting countries with case counts

4. **Reporter qualification table**:
   - Physician, pharmacist, other health professional, consumer — with counts

5. **Drug characterization table**:
   - Suspect, concomitant, interacting — with counts and percentages

## Formatting:
- Use Markdown tables for structured data.
- Include brief interpretive text between tables, but keep the focus on the data.
- All numbers must come from the evidence packet.
